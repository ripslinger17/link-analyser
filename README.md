# Link Analyser

FastAPI service + browser UI that validates a website, cleans its homepage, researches competitors with Serper, and returns one structured SEO/business report generated with Gemini.

- UI: `http://localhost:4000/`
- API docs: `http://localhost:4000/docs`
- Only API route: `POST /link-analysis`

## 1. Setup

Tested with Python 3.14.6; Python 3.10+ should work.

```bash
python3 -m venv .link_analyser
source .link_analyser/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
```

Fill `.env`:

```dotenv
GEMINI_API=your_real_gemini_api_key
SERPER_API=your_real_serper_api_key
```

Start the server on port **4000**:

```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 4000
```

*Note: Running bare `uvicorn app.main:app --reload` defaults to port 8000. Use the command above.*


## 2. API contract

### Request body

The evaluator-facing key is `url`. The older `link` key is still accepted.

```json
{
  "url": "https://example.com",
}
```

`model` is optional. Supported ids are:

- `gemini-3.5-flash-lite`
- `gemini-3.6-flash`
- `gemini-3.8-flash`

### Response modes

- `POST /link-analysis` → one plain JSON report.

SSE event order:

### Sample request

```bash
curl -X POST http://localhost:4000/link-analysis \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'
```

## 3. What the pipeline does

1. Validate format, public host, DNS and reachability.
2. Fetch and clean the homepage. Save raw + clean HTML and favicon under `app/data/`.
3. Ask Gemini for three competitor-discovery queries, search them with Serper, deduplicate by host, and scrape the requested three to ten competitor homepages.
4. Generate five report sections with Gemini:
   1. Competitor comparison table (brand + the requested competitors)
   2. Five target search queries with platform, intent, relevance and audience
   3. SEO improvements (keywords, title, meta description, support content)
   4. Five services with the exact columns `Service Name`, `Description`, `Target Industry`, `Target Customer`, `Main Benefit`; inferred rows are labelled `(AI-generated suggestion)`
   5. Target audience with all nine required labels
5. Return one JSON object.

Search platforms are restricted to Google, Facebook, Instagram, LinkedIn and X. No search-volume numbers are invented.

An optional same-host crawler with `max_pages=50` and `max_depth=3` exists in `app/utils/crawler.py`; it is not wired into `/link-analysis` because the practical test only needs homepage-level analysis.

## 5. LLM provider comparison

Prices checked on **26 November 2026** from the official pricing pages. All values are USD per 1M tokens, standard/paid tier unless stated.

| Provider | Candidate | Input | Output | Fit for this project |
| --- | --- | ---: | ---: | --- |
| Google | `gemini-3.5-flash-lite` | $0.30 | $2.50 | Free tier available; low-latency, high-volume extraction; already integrated through the Interactions API. |
| Google | `gemini-3.8-flash` | $0.75 | $3.75 (until 31 Dec 2026) | Stronger reasoning; same integration, higher cost. Exposed in the UI. |
| OpenAI | `gpt-6-luna` | $0.10 | $0.50 | Cheapest paid tier here, but needs a new client/SDK and prompt-regression work. |
| Anthropic | Claude Haiku 5.5 (≤100k prompt) | $0.10 | $0.50 | Strong low-cost option; needs a new client/SDK. Claude 4.7+ tokenizers can produce ~30% more tokens for the same text, which affects real cost. |

### Final recommendation

**I would recommend *`GPT-6-Luna`* because it is the cheapest with decent enough intellinege with maximum thinking.**

Because no free API was available *Gemini Models* are being used here.

### Cost estimate per analysis

The default pipeline makes six AI calls. This build caps cleaned page text at 20,000 characters per site, so the default report is roughly **45k input + 6k output tokens**. Requesting more competitors increases the comparison-table input and output proportionally. 

If using `GPT-6-Luna` then total Input cost will be 45,000 x 3 = 1,35,000 tokens = $0.00675 and Output cost will be 6,000 x 3 = 18,000 tokens = $0.00450.
